Issues are used both to track work and to distribute tasks to agents. Create, read, assign, and update issues through the configured Linear integration.

## Workflow

- Use the Activi team and this repository's existing Linear project. Do not create a second project to escape the rejected title.
- Ask which team or project to use when the target cannot be determined.
- Give each issue a clear title, sufficient implementation context, and acceptance criteria.
- Assign the issue to the responsible agent or human when known.
- Apply the triage labels defined in `docs/agents/triage-labels.md`.
- Keep the issue status and assignment synchronized with the actual state of the work.
- Do not create a duplicate local or GitHub issue unless explicitly requested.
