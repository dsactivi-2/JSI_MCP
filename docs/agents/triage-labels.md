# Triage Labels

Status date: 7 October 2026.

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings to use in the Activi Linear team.

| Label in mattpocock/skills | Label in Linear   | Meaning                                  |
| -------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human` | Requires human implementation            |
| `wontfix`                  | `wontfix`         | Will not be actioned                     |

When a skill mentions a canonical role, use the corresponding Linear label from this table.

Do not invent a sixth label. These five names were not rechecked in the Linear workspace on 7 October 2026. If the workspace does not have one of them, say so and do not apply a substitute.
