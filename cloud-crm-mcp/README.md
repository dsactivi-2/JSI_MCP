# Cloud CRM MCP

Read-only MCP server for the existing CRM MySQL database. The source in this folder is TypeScript and uses mcp-use. Manufact hosts the running copy. This package is not the old Cloudflare Worker.

- Live server: https://calm-forge-hk9rc.run.mcp-use.com/mcp
- Public page: https://github.com/dsactivi-2/JSI_MCP
- Package version: 0.1.0, the same version the server reports to clients

The running deployment recorded on 6 October 2026 is `2a078755`. This source is newer than that deployment. A client sees the website address and the connection text below only after the next deploy.

## What is in this folder

- `index.ts` and `src/`: phase-1 read tools.
- `skills/crm-kandidatensuche/SKILL.md`: the one skill for every client.
- `skills/crm-kandidatensuche/agents/openai.yaml`: an OpenAI hint only. It is not a second skill.
- `test/`: local checks. They do not read a candidate row.

Connecting does not install the skill. The server tells a client to ignore old local skill files and to read `skill://crm-kandidatensuche/SKILL.md`. A client that never reads that skill does not receive the long guide.

## Login

Without OAuth settings, the server expects `Authorization: Bearer` and `CRM_MCP_SERVER_TOKEN`. A token in the URL is rejected.

The live server uses WorkOS. Set `MCP_USE_OAUTH_WORKOS_SUBDOMAIN` to the AuthKit address, and set `OAUTH_RESOURCE` or `MCP_URL` to the `/mcp` address. Those two values replace separate issuer, authorize, token, and JWKS settings. Discovery then advertises `openid`, `profile`, `email`, and `offline_access`. It does not advertise `crm:read`. Only `crm_query` declares `sql:read`. No tool handler checks the WorkOS role. The shared token remains a fallback and is treated as if it had the CRM scopes. `OAUTH_CLIENT_SECRET` is not a server setting.

For a provider that is not WorkOS, set `OAUTH_ISSUER`, `OAUTH_AUTHORIZATION_ENDPOINT`, `OAUTH_TOKEN_ENDPOINT`, `OAUTH_JWKS_URL`, and `OAUTH_RESOURCE` or `MCP_URL` together. A partial set does not start.

## Database

`CRM_DATABASE_URL` is the full MySQL address, including user and password. No second password variable is used. It is set on Manufact and is not stored in Git. TLS uses the Aiven project CA in `src/aiven-ca.ts`. The server reads the same existing database through this connection. It refuses the old Worker host and the old Hyperdrive id.

## Local checks

```bash
npm install
npm test
npm run typecheck
```

`npm run dev` serves a local inspector at http://localhost:3000/mcp/inspector. The hosted server does not publish `/mcp/inspector`. `mcp-env.d.ts` is generated by `npm run typecheck` for mcp-use view typing. Do not edit it by hand. This server has no views, so that file only points at `index.ts`.

## Deploy

Manufact is the temporary host. Cloudflare is a later option. Deploy only when that is the requested step:

```bash
npm run deploy
```
